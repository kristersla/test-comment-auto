Data Deletion Instructions

Instagram Comments Test is a locally run tool, not a hosted service. The current script does not store data on a developer-operated server.

  1. Delete the local files instagram_comments.csv and instagram_comments.json and any copies you created.
  2. Revoke this test app's permissions through your Instagram account's connected apps/settings.
  3. Delete any locally saved access token.

These steps delete data held by the local testing tool. They do not delete original comments or posts hosted on Instagram.
