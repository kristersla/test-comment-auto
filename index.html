Instagram Comments Test: Privacy Policy

Last updated: 14 October 2026

Instagram Comments Test is a small, locally run application used to test Meta's Instagram API with the developer's own authorized Instagram professional account. It is not offered as a public service.

Data accessed

When an Instagram account owner authorizes access, the test app may retrieve the account ID and username, posts and media metadata, comment text, commenter usernames, comment IDs, timestamps and replies. The app uses an Instagram User Access Token provided by the account owner.

Purpose and storage

Data is accessed only to test Instagram comment retrieval and, if the account owner chooses in a future test, the ability to reply to comments. The current script runs on the user's computer and can export results to local CSV and JSON files. It does not upload comment exports or access tokens to a developer-operated server or database. Tokens are entered locally for API requests. The script does not intentionally retain tokens after execution.

Sharing and security

API requests are sent to Meta's Instagram API. No comment data is sold, used for advertising, or shared with unrelated third parties by this test application. Users should protect access tokens and local export files and should not publish either publicly.

Retention and deletion

Data remains in local exports until the user deletes those files. To delete it, remove the exported CSV and JSON files from the computer. To revoke ongoing Instagram API access, remove the app's access through Instagram's connected-app settings. For more information, see the data deletion instructions.
